# Jev 判定チャットサイト

メッセージを送ると、TypeSafe AI（Jev）が「特定の内容が含まれているか」を判定し、
その結果に応じた文章で返事をするサイトです。

## 使い方

1. Node.js (18以上推奨) をインストールしておく
2. このフォルダで依存パッケージをインストール

   ```
   npm install
   ```

3. TypeSafe AIの招待時にもらったAPIキーを環境変数にセットして起動

   ```
   export TYPESAFE_AI_API_KEY="ここに自分のAPIキー"
   npm start
   ```

   (Windowsの場合は `set TYPESAFE_AI_API_KEY=ここに自分のAPIキー` を使ってください)

4. ブラウザで `http://localhost:3000` を開く

## 返事の内容を変える

`server.js` の上のほうにある2つの設定を書き換えます。

### 1. `QUESTIONS` — Jevに何を聞くか

「はい/いいえ」で答えられる日本語の質問を並べます。項目を足すほど、
判別できる内容が増えます。

```js
const QUESTIONS = {
  greeting: 'このメッセージは挨拶（こんにちは、おはよう、はじめまして など）か？',
  identity: 'このメッセージは、相手が誰なのか（名前・正体・何者なのか）を尋ねているか？',
  cancel: 'このメッセージに、キャンセル・解約・取り消しの意図が含まれているか？',
  thanks: 'このメッセージは、お礼や感謝を述べているか？',
};
```

### 2. `RULES` — 判定結果ごとに何を返すか

上から順に照合し、最初に当てはまったものを返します。
**具体的な条件（複数の組み合わせ）ほど上に置いてください。**

```js
const RULES = [
  {
    name: 'greeting+identity',
    when: (is) => is.greeting && is.identity,
    reply: 'こんにちは！jevです。',
  },
  // ...
];
```

`is.greeting` などは、対応する質問の確率が0.5以上なら `true` になります。
どのルールにも当てはまらなかった場合は `FALLBACK_REPLY` が返ります。

## 生成モード（実験）

画面上部で「生成モード」に切り替えると、`/api/generate` を使い、
**Jevだけで文章を組み立てます。**

Jevは文章を生成しませんが、`choice` 型で「候補のうちどれが最も適切か」を
選ばせることはできます。これを使って、文を3つの枠に分けて埋めます。

| 枠 | 例 |
|---|---|
| 書き出し | なし / こんにちは！ / なるほど、 |
| 本体 | jevです。/ メッセージに特定の内容が含まれているかを判定できます。 |
| 結び | なし / なにか聞きたいことはありますか？ |

Jevは**全質問を1リクエストでまとめて評価する**ので、3枠ぶんの選択は
**1往復**で済みます。そのあと本体を2位・3位の候補に差し替えた案を作り、
`score` と `choice` で**文として比べて**一番良いものを採用します（2往復目）。

画面には選択の過程（各枠の候補と確率、比較した案とその結果）が表示されます。

### なぜ1語ずつ生成しないのか

最初は「1語選ぶ → 下書きに足す → また選ぶ」を繰り返す方式で作りましたが、
実際に動かすと破綻しました。

```
1手目: 、できます 64%
2手目: 、できます 62%   ← draftが伸びても
3手目: 、できます 66%   ← 分布がほぼ変わらない
```

Jevは下書きの続きを予測するのではなく、**毎回 message に対する答えを
選び直していました。** 同じ質問を繰り返しても状態が進まないため、
「、できます、できませんはいいいえ、わかりました」のような
矛盾した文ができてしまいます。

そこで同じ質問を繰り返すのをやめ、**役割の違う枠をそれぞれ別の質問として
一度に埋める**形にしました。

### 候補を変える

`generate.js` の `SLOTS` を書き換えます。
`text` が実際に出力される文字列、`description` はJevへの説明です。

```js
export const SLOTS = [
  {
    key: 'body',
    description: '返事の本体',
    options: {
      名乗る: { text: 'jevです。', description: '相手が名前や正体を尋ねたとき' },
      // ...
    },
  },
];
```

**どの枠にも「当てはまらない」選択肢を用意してください。** `choice` は必ず
何かを返すので、逃げ道がないと見当違いの候補を無理やり選びます。
書き出しと結びの「なし」、本体の「不明」がその役割です。

`choice` は1問あたり255個まで選択肢を持てます。

## 動作の仕組み

- ブラウザ → 自分のサーバー(`server.js`) → TypeSafe AI(Jev) の順でリクエストが流れます
- Jevは boolean（true/falseの確率）を返すので、確率0.5を境目に true / false を決めています
- 実際の返事の文章は `RULES` にあらかじめ書いておいた定型文です
  （Jev自体は自由な文章を生成しないため）
- 完全に自由な文章で返事をさせたい場合は、文章生成ができる別のAIモデルが必要です
